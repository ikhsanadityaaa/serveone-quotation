# V10 update

This release focuses on Create Quotation stability, Master Data structure, and PDF readability.

- Client and Attention start blank on a fresh Create Quotation page.
- Client selection is now stable when Attention changes; Attention no longer clears the selected Client.
- Attention uses the searchable white dropdown component.
- UOM input is searchable while the cell itself keeps only the UOM code (for example `EA`).
- RFQ No. and Sales PIC controls keep matching heights when Sales PIC shows email/phone.
- Client Address is stored once per Client in the Master Data editor. Attention rows no longer have separate Address inputs.
- KPI Amount in Quotation List is calculated before VAT.
- PDF information section is more compact, its labels are left aligned, table text is larger, and the totals block is centered below the item table.
- Removed the GitHub signature-location note from Master Data.
